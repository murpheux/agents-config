1. Summary

Claude Code is the closest match to the OpenCode design. Since 2026 its settings.json accepts "agent": "router", so the main session itself runs as a cheap Haiku router. The shared guard hook keeps that main thread read-only, which forces delegation to seven specialist subagents on the right model tier. Enforcement is layered: permissions.deny (always wins, even in bypass mode), the PreToolUse guard hook, the OS sandbox, and credential scrubbing of subprocess environments.

5. Cost levers

  • Haiku router plus isolated subagent contexts: the router never carries implementation transcripts.
  • Explore overridden to Haiku; /commit /explain /summarize /pr pinned to Haiku.
  • autoCompactWindow: 200000, BASH_MAX_OUTPUT_LENGTH=20000, subagent depth 2 / 4 concurrent, maxTurns per agent.
  • Skills load on demand; a status line shows $ and context % live; npx ccusage for history.
  • Not used: advisorModel. Each advisor call re-reads the whole conversation uncached, and it needs pass-through to the Anthropic API.

6. Guardrails

  1. permissions.deny: push, reset --hard, filter-branch, root/home rm, disk tools, destroy, -auto-approve, bucket/namespace deletion, secret-printing commands, secret files, .git/** edits, 1Password MCP.
  2. Guard hook: 33 regex rules and 18 protected-path patterns, for cases prefix rules miss (git -C x push -f, curl | sh, .env.* with example exceptions, interactive programs). It also runs the router gate.
  3. Sandbox: writes confined to the project; network limited to package registries and docs, and a new domain prompts; cloud and cluster CLIs are excluded and go through normal prompts.
  4. CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1, DISABLE_TELEMETRY=1, enableAllProjectMcpServers: false.

8. Gotchas handled

  • Deny beats allow and can't be carved out, so .env.example exceptions live in the hook rather than in deny rules.
  • Bash rules are text-based and can be routed around (sh -c, absolute paths); the hook and sandbox are the real boundary.
  • A leading / in user settings means ~/.claude/, so all path rules use ~/ or **/.
  • Hooks fail open on a wrong path or a timeout; the installer runs the guard self-test and aborts on failure.
  • CLAUDE_CODE_SUBAGENT_MODEL no longer overrides frontmatter, so every agent pins its own model.
  • A non-Anthropic gateway disables MCP tool search, which is why the gateway is an opt-in overlay.
